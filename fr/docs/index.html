Le manuel de Verbinal

Tout ce que vous pouvez faire dans Verbinal pour macOS, écran par écran et sous forme de tâches, a maintenant son propre site : docs.verbinal.com.

Lire le manuel Read in English

Ce qu’est docs.verbinal.com

docs.verbinal.com est le manuel de l’utilisateur de Verbinal pour macOS 1.4, l’app Mac du Centre canadien de données astronomiques (CADC) et de la plateforme scientifique CANFAR. Il est écrit pour quelqu’un qui n’a jamais ouvert l’app : il commence par les premiers pas et la connexion, parcourt chaque écran — la recherche dans l’archive, Recherche, les visionneuses FITS et Cube, les sessions et les tâches en lot du Portail, le Stockage, le Calcul à distance et les Flux de travail — et se termine par le travail avec un assistant IA, les Réglages, la confidentialité et le dépannage. Chaque chapitre donne d’abord les tâches, puis les commandes, et cite les libellés de l’app exactement tels qu’ils apparaissent à l’écran. Il se lit de la même façon en français et en anglais, offre une recherche, et propose sur chaque page un lien pour suggérer une modification sur GitHub.

Chaque chapitre consacré à un écran se termine par ce qu’un assistant IA peut y faire, et le chapitre Travailler avec un assistant IA explique ce que vous décidez : quelles sessions vous autorisez, ce qu’il peut faire sans demander, et où lire ce qu’il a fait.

Pour les agents IA

Le manuel est écrit pour des personnes, et un assistant le lit tout aussi bien. llms.txt liste chacune de ses pages avec un lien vers son Markdown, pour qu’un agent puisse lire le manuel directement. Pour connecter un agent à Verbinal lui-même, AGENTS.md, dans le dépôt, donne la commande et l’entrée pour chaque client.

Les autres apps

Le manuel porte sur l’app Mac. Pour Verbinal pour Windows, Linux et Android, les articles de version de ce blogue présentent chaque version, et le dépôt GitHub de chaque app a son README : Windows, Linux, Android.

Ouvrir le manuel

Gratuit à lire, sans compte. L’app qu’il décrit est gratuite sur le Mac App Store, et son code source est sur GitHub.
