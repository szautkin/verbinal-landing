What docs.verbinal.com is

docs.verbinal.com is the user manual for Verbinal for macOS 1.4, the Mac app for the Canadian Astronomy Data Centre (CADC) and the CANFAR science platform. It is written for someone who has never opened the app: it starts with getting set up and signing in, walks through every screen — the archive search, Research, the FITS and Cube viewers, the Portal's sessions and batch jobs, Storage, Remote Compute and Workflows — and ends with working alongside an AI assistant, Settings, privacy and troubleshooting. Each chapter puts the tasks first, the controls after, and quotes the app's labels exactly as they appear on screen. It reads the same in English and in French, can be searched, and has a link on every page to suggest a change on GitHub.

Every chapter about a screen ends with what an AI assistant can do there, and the chapter on working with an AI assistant explains what you decide: which sessions you allow, what it may do without asking, and where to read what it did.

For AI agents

The manual is written for people, and it is just as readable by an assistant. llms.txt lists every page of it with a link to its Markdown, so an agent can read the manual directly. To connect an agent to Verbinal itself, AGENTS.md in the repository gives the command and the entry for each client.

The other apps

The manual covers the Mac app. For Verbinal for Windows, Linux and Android, the release posts on this blog walk through each version, and each app's repository on GitHub has its README: Windows, Linux, Android.
